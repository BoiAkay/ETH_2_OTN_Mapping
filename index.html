Structure and rates per ITU-T G.709 (OTN interfaces) and ITU-T G.7041 (GFP). Container rates for ODU2e, ODU3e2, and ODU4 drawn from published vendor mapping tables; GFP-F header fields (PLI, cHEC, tHEC) are computed here with the actual G.7041 CRC-16 polynomial (x¹⁶+x¹²+x⁵+1, init 0) and the standard Ethernet CRC-32. The BMP and GMP visualizations are pedagogical simplifications of the justification process, not bit-exact encoder output — real GMP signals a per-frame byte count (Cm) rather than a static pattern.

This is an educational visualization, not a certified encoder. Built as a static page — safe to push to a GitHub repo and serve directly with GitHub Pages.
